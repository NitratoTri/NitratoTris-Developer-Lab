# NitratoTris Developer Lab

A public engineering portfolio and programming-practice workspace covering backend, frontend, databases, automation, software quality, and algorithmic problem solving.

## Tracks

- **Portfolio projects:** practical applications with clear requirements, architecture notes, tests, and setup instructions.
- **Coding challenges:** progressively harder problems with readable implementations, edge cases, tests, and complexity analysis.
- **Engineering practices:** CI workflows, Docker, API documentation, security fundamentals, and maintainable project structure.

## Repository standards

Every contribution should be useful, reproducible, and reviewable. Avoid filler commits, copied solutions without attribution, secrets, and unverified claims about test execution. Include the exact commands needed to run checks and clearly report which checks were actually executed.

## AI assistance and authorship

Some work in this repository may be prepared with AI assistance. The repository should describe that accurately. The account owner should review, understand, adapt, and be able to explain each contribution before presenting it as their work in a CV or interview.
